# GPS-мост

Передаёт GPS с одного Android-телефона (отправитель, хороший GPS) на другой (получатель, навигатор).
На получателе координаты подставляются системе как «фиктивное местоположение», и любой навигатор
видит их как свои.

- Каналы: Wi-Fi / точка доступа (UDP) или Bluetooth (RFCOMM). Выбирается в приложении.
- Отправитель работает с погашенным экраном (foreground-сервис), так что AMOLED можно не включать.
  Интерфейс чисто чёрный.
- Root нужен только для удобства: выдать права mock одной кнопкой и погасить экран.
  Без root всё делается вручную через настройки разработчика.

## Как получить APK

### Вариант 1. GitHub (без Android Studio, всё из браузера)
1. Создай репозиторий на github.com и загрузи в него все файлы проекта (включая скрытую папку `.github`).
   Если браузер не загрузил `.github`, создай файл вручную: Add file → Create new file →
   имя `.github/workflows/build.yml`, содержимое возьми из этого проекта.
2. Вкладка **Actions** → **Build APK** → **Run workflow** (или сборка стартует сама после загрузки).
3. Через 3–5 минут в завершённом запуске внизу появится артефакт **gps-bridge-apk**. Скачай и распакуй,
   внутри `app-debug.apk`.

### Вариант 2. Android Studio
Открой папку проекта, дождись синхронизации, Build → Build APK(s).
Файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 3. Командная строка (нужны JDK 17 и Android SDK)
`./gradlew assembleDebug`

## Установка и настройка

Установи APK на оба телефона (разреши установку из неизвестных источников).

### Получатель (старый телефон)
1. Открой приложение, выбери **Получатель** и канал.
2. Дай права на подмену GPS одним из способов:
   - кнопка **Выдать права mock через root** (подтверди запрос root);
   - или вручную: Настройки → Для разработчиков → «Выбрать приложение для фиктивных местоположений» → GPS-мост;
   - или с компьютера: `adb shell appops set com.example.gpsbridge android:mock_location allow`.
3. Кнопка **Не засыпать** → разреши работу без ограничений батареи.
4. Нажми **Запустить**. Статус покажет «Подмена GPS: включена».
5. Открой навигатор. Для надёжности можно в настройках отключить определение местоположения по Wi-Fi/сетям.

### Отправитель (новый телефон)
1. Включи геолокацию (GPS) в системе.
2. Выбери **Отправитель** и тот же канал. Выдай разрешение на геолокацию и уведомления.
3. **Запустить**, затем просто заблокируй экран (или кнопка **Погасить экран (root)**).
   Сервис продолжит работать, экран не светится.

### Wi-Fi / точка доступа
- Включи точку доступа на новом телефоне, подключи к ней старый.
- Ничего вводить не нужно: получатель сам шлёт «привет» на шлюз (это и есть телефон-точка доступа),
  отправитель запоминает его и шлёт координаты.
- Если телефоны в обычной Wi-Fi-сети (не в точке доступа) или роли наоборот (точка доступа на старом),
  впиши IP другого телефона в поле IP. Свои IP показаны в приложении.
- Поле «Ключ» необязательное: если задать одинаковое слово на обоих, чужие пакеты в сети игнорируются.
- Порт по умолчанию 45678 (одинаковый на обоих).

### Bluetooth
1. Сопряги телефоны в настройках Bluetooth (один раз).
2. На получателе: роль «Получатель», канал Bluetooth, Запустить (он ждёт подключения).
3. На отправителе: канал Bluetooth, выбери получателя в списке, Запустить.
4. При обрыве отправитель переподключается сам каждые 2 секунды.

## Известные ограничения
- Часть приложений (банки, некоторые игры, иногда навигаторы) определяют подмену GPS и отказываются работать.
  Тогда на получателе с root помогают модули скрытия mock-местоположения (LSPosed/Zygisk), приложение их не включает.
- Система помечает такие координаты как «mock»; убрать пометку из приложения нельзя.
- Если сервис убит системой (агрессивная прошивка), запусти его заново. Автоперезапуска нет.
- Точки передаются раз в секунду, как их отдаёт GPS отправителя.
